# Website Desa Cikondang

Paket awal frontend statis untuk GitHub Pages/hosting statis.

## Isi
- `index.html` halaman beranda dengan menu Tentang, Dokumen, Berita, Sosial Media, Kelembagaan, Pencapaian PBB.
- `assets/` CSS dan JavaScript halaman publik.
- `uploads/dashboard-desa.svg` ilustrasi sementara dashboard desa.
- `admin/` tampilan panel admin demo.

## Cara mencoba
Buka `index.html` melalui browser atau unggah seluruh isi folder ke repository.

## Catatan penting tentang Admin
Panel ini hanya DEMO sisi browser. Login demo: username `admin`, password `cikondang2026`. Data disimpan di localStorage browser/perangkat yang dipakai, bukan database server. Jangan gunakan untuk mengelola data resmi atau memasang sebagai login publik yang aman. Agar admin bisa login aman dan perubahan terlihat oleh semua pengunjung/perangkat, perlu backend/API, database, dan autentikasi server (misalnya PHP + MySQL atau layanan backend).
